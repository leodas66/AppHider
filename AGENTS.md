# Repo notes

- `plan.md` is the source of truth for scope: "App Hider", a rooted-Android app. Phases 0–5 are the MVP; Phase 6 is OTA updates; "Later extras" are out of scope.
- Single-module Kotlin/Compose Android app in `app/` (namespace `com.vishwa.apphider`), Gradle Kotlin DSL. `plan.md` is docs only, not generated from code.
- Build command (verified): `./gradlew :app:assembleDebug`. No custom lint/typecheck/test scripts exist; use Gradle tasks directly.
- Toolchain in this sandbox: JDK 21, Android SDK at `/data/home/Android/Sdk` (platform 35, build-tools 35.0.0, platform-tools), Gradle 8.9 wrapper. `local.properties` is machine-specific and gitignored.
- Constraints from the plan: root via `pm hide` / `pm unhide`; `QUERY_ALL_PACKAGES` needed to list apps; Room is the source of truth because hidden apps drop out of normal package queries; keep a strict protected-package list; prefer shell commands over reflection (non-SDK restrictions). Detect root by actually getting a shell and checking `Shell.getShell { it.isRoot }` (as in Amarok), not `Shell.isAppGrantedRoot()` — the latter returns `null` when a `su` binary merely exists in PATH and reports false with KernelSU.
- `AppContainer` is the manual DI root; `MainViewModel` drives all screens. `shouldBeHidden` in Room is user intent; actual hide state is on the device via `RootManager`.
- Git repo at `https://github.com/leodas66/AppHider` (public), default branch `main`. Commits are authored as `leodas66` via per-command `-c user.name/-c user.email`; no global git identity is configured.
- `.github/workflows/release.yml` runs on `v*` tags and publishes ABI-split **debug and signed release** APKs (arm64-v8a, armeabi-v7a, x86, x86_64, universal) plus `ota.json` to a GitHub Release. It sets `VERSION_CODE=$((RUN_NUMBER + 1000))` and `VERSION_NAME=<tag>` for both the APKs and the manifest.
- OTA updater fetches `https://github.com/leodas66/AppHider/releases/latest/download/ota.json`, selects the APK by `Build.SUPPORTED_ABIS` (universal fallback), verifies the package name and signing certificate, then installs silently via root `pm install -r -d`. **The repo must be public**; otherwise that URL is inaccessible without auth. Debug builds have a different signature, so OTA install can only be tested from a signed release build.
- Release signing uses repo secrets `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. The PKCS12 keystore lives outside the repo at `/data/workspace/apphider-release.jks`; passwords at `/data/workspace/apphider-release.env`. Store and key password must match (PKCS12 ignores a separate `-keypass`).
- `MainActivity` must be a `FragmentActivity` for `BiometricPrompt`. Don't use `ActivityResultContracts` for permissions there — its generated request codes exceed 16 bits and crash on startup; use `ActivityCompat.requestPermissions` with a fixed small code.
